## Description

The flow the user wants: type resolve-merge-conflicts, pick an agent (claude/codex), pick a model, see the prompt (with conflicted files filled in), amend it in an editor, confirm, run the agent, get a report. Every question answerable by a flag (-a/--agent, -m/--model, -y/--yes, -c/--cwd, --prompt-file) for scripted runs.
